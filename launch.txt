1) docker compose up --build        # первая сборка + запуск
   docker compose up                 # дальнейшие запуски
   docker compose up -d              # в фоне

2) Проверка сервисов:
   - Swagger API:        http://localhost:8000/docs
   - WebSocket клиент:   python -m src.skill_matrix.communication.client <user_id>
   - RabbitMQ management: http://localhost:15672  (guest / guest)

3) Логи и остановка:
   docker compose logs -f api
   docker compose logs -f notification
   docker compose down              # остановка (данные БД сохранятся)
   docker compose down -v         # остановка и удаление данных БД
